# وب‌سایت طرح جامع هوش مصنوعی در صنایع استان البرز

ارائه‌دهنده: **دکتر مهدی باقری‌زاده** — عضو هیئت علمی گروه مهندسی کامپیوتر، دانشگاه آزاد اسلامی واحد کرج

وب‌سایت چندصفحه‌ای فارسی (RTL) با Next.js 14 (App Router)، React، TypeScript و Tailwind CSS. بدون پایگاه داده و بدون API خارجی اجرا می‌شود.

## اجرا روی کامپیوتر

```bash
npm install
npm run dev      # توسعه:  http://localhost:3000
npm run build    # ساخت نسخه تولید
npm start        # اجرای نسخه ساخته‌شده
```

نیازمندی: Node.js ‏18.18 یا بالاتر.

> فونت Vazirmatn هنگام build از Google Fonts دریافت می‌شود (در Vercel مشکلی ندارد). اگر محیط شما اینترنت ندارد، فونت را محلی کنید (`next/font/local`).

## قبل از انتشار حتماً تنظیم کنید — `config/site.ts`

| مورد | کلید |
|---|---|
| ایمیل مقصد فرم‌ها | `contact.email` (فعلاً جای‌نگهدار) |
| شماره تماس و نشانی | `contact.phone`, `contact.address` |
| آدرس سایت (sitemap و Open Graph) | `siteUrl` |
| عکس رسمی ارائه‌دهنده | فایل را در `public/images/presenter.jpg` بگذارید و `presenter.photo` را `"/images/presenter.jpg"` کنید |
| اتصال به سرویس فرم (اختیاری، مثل Formspree) | `contact.formEndpoint` |

هیچ ایمیل، تلفن یا رمزی در کد ساختگی نیست. هیچ API Key در پروژه وجود ندارد.

## ساختار

```
app/            صفحات (proposal, courses, projects, industries, case-studies, methodology, about, contact, references)
components/     کامپوننت‌های قابل استفاده مجدد
data/           محتوای سایت (دوره‌ها، پروژه‌ها، صنایع، مطالعات موردی، منابع، متن پروپوزال)
config/         تنظیمات سایت و منوی ناوبری
public/         تصاویر و آیکون‌ها
docs/           راهنمای GitHub/Vercel و فهرست کنترل محتوا
```

برای ویرایش محتوا فقط فایل‌های `data/` را تغییر دهید؛ همه صفحات از آن‌ها تغذیه می‌شوند.

## فرم‌ها چگونه کار می‌کنند؟

سایت سرور ندارد. با ثبت فرم، خلاصه درخواست نمایش داده می‌شود و کاربر می‌تواند آن را با **mailto** ارسال یا کپی کند. اگر `contact.formEndpoint` تنظیم شود، فرم به همان سرویس نیز POST می‌کند. سایت هیچ‌جا وانمود نمی‌کند اطلاعات روی سرور ذخیره شده است.

## چاپ / PDF

در صفحه «پروپوزال» دکمه «چاپ / ذخیره PDF» وجود دارد (چاپ مرورگر؛ منو و فوتر در چاپ پنهان می‌شوند).

## ملاحظات محتوایی

- همه پروژه‌ها «پیشنهادی و قابل امکان‌سنجی» معرفی شده‌اند؛ ادعای اجرای قبلی ندارند.
- پروژه‌های پیشرفته با برچسب «نیازمند امکان‌سنجی و همکاری تخصصی» نمایش داده می‌شوند.
- مطالعات موردی خارجی فقط با ارقام نقل‌شده از منبع اصلی و با لینک؛ نمایانگر همکاری رسمی نیستند.
- مطالب افزوده‌شده که در پروپوزال نبوده با برچسب «تکمیلی» یا کادر نقطه‌چین مشخص‌اند.
